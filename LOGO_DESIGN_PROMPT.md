# Logo Tasarım Prompt'u

## Sistem Bilgileri
- **Sistem Adı:** Product Search System / Barcode SaaS System
- **Ana Özellik:** Profesyonel Barkod Arama Sistemi
- **Kullanım:** B2B SaaS, Ürün Yönetimi, Barkod Tarama
- **Hedef Kitle:** İşletmeler, Depo Yöneticileri, Perakende

## Tasarım Stili
- **Renkler:** 
  - Ana: Mavi-Mor Gradient (#3B82F6 → #6366F1)
  - Vurgu: Beyaz, Açık Gri
- **Stil:** Modern, Minimalist, Profesyonel
- **Efektler:** Glass morphism, Gradient, Soft shadows

## Teknik Gereksinimler

### Formatlar
- **SVG** (öncelikli - vektör, ölçeklenebilir)
- **PNG** (şeffaf arka plan, 512x512, 1024x1024)
- **Favicon** (32x32, 64x64, 128x128)

### Kullanım Alanları
- Favicon (tarayıcı sekmesi)
- Header logo
- Login sayfası
- Admin panel
- Email şablonları
- Mobil uygulama (gelecekte)

### Renk Varyasyonları
- **Ana:** Gradient (mavi-mor)
- **Koyu arka plan için:** Beyaz/açık gri versiyon
- **Açık arka plan için:** Koyu versiyon
- **Monokrom:** Siyah/beyaz versiyon
