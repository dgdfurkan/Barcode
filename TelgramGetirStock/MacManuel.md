🚀✨ Projeyi terminalden çalıştırmak için MEGA Kolay Adımlar! ✨🚀

1️⃣ Python sürümünü kontrol et  
   python3 --version (3.9+ olmalı)

2️⃣ Proje dizinine gir  
   cd /path/to/TelgramGetirStock

3️⃣ Sanal ortamı kur  
   python3 -m venv venv

4️⃣ Sanal ortamı aktif et  
   source venv/bin/activate

5️⃣ Gerekli bağımlılıkları yükle  
   pip install -r requirements.txt

6️⃣ .env dosyasına Telegram bot tokenı ve Getir API bilgilerini ekle  
   (READMEdeki formata bakmayı unutma)

7️⃣ Botu başlat  
   python main.py





🚀✨ Botu durdurup yeniden başlat! ✨🚀
   Botu durdurmak için terminalde `Ctrl + C` (Mac’te `⌃ + C`) tuşlarına bas  
   
1️⃣ Sanal ortam kapandıysa tekrar aktif et:  
    source venv/bin/activate  
   
2️⃣ Botu tekrar başlat:  
    python main.py
